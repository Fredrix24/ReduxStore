## 📱 О проекте

Интерактивная корзина интернет-магазина с полным управлением состоянием через **Redux**. Проект демонстрирует работу с глобальным состоянием, динамическое добавление/удаление товаров и валидацию данных.

### ✨ Возможности

- ✅ Увеличение/уменьшение количества товаров
- ✅ Ограничение количества от 1 до 25 единиц
- ✅ Добавление новых товаров через диалоговое окно
